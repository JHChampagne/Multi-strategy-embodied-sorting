# M1 简历描述参考

项目名称：**基于 SO-ARM100 的多策略物料分拣工作站**

- 基于 MuJoCo 构建统一机械臂工作站，设计观测、动作和策略接口，将脚本专家、RGB-D 视觉抓取、ACT、SmolVLA 及 RL 技能环境接入同一仿真核心；支持三类物料、三个托盘及可复现评测。
- 实现“视觉定位 → 学习动力学模型 CEM-MPC 接近 → IK 抓放”的分段协同控制链，加入策略交接、接触检查、重观测和失败重试；在 20 个固定测试布局上完成 20/20 场分拣，无专家兜底。
- 使用 8,000 条真实仿真交互训练轻量动力学集成模型，Reach 测试 20/20；集成开源 ACT/SmolVLA 权重，在原抓放任务分别取得 20/20、18/20；打通 SAC 训练与检查点恢复，以及 LeRobot 示范导出和读回。

描述时应同时说明：上述结果来自仿真固定回归集；ACT/VLA 权重来自上游，几何算法与世界模型以 WorkCell 为基础适配；两者直接迁移到分拣仍为 0/5；SAC 当前只有 4,096 步管道验证，未学会 Reach/Lift。M2 完成训练前不写“所有策略均能独立分拣”。

算法岗位可重点展开动作语义、特权状态边界、模型滚动误差、采样效率和迁移失败；开发岗位可重点展开统一执行接口、资源管理、数据管道、测试和可复现性。具体数值以 `RESULTS.md` 和逐回合报告为准。
